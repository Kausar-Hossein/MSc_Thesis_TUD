# MSc Thesis – Groundwater Availability in Saxony

## Groundwater Availability in Saxony: Assessing Regional Variations and Climate Impacts

This repository contains the Python/Jupyter Notebook scripts developed for my MSc thesis on groundwater availability in Saxony, Germany.

The study evaluates temporal and regional variations in groundwater storage and recharge using groundwater-level and streamflow observations. Different hydrological methods are applied and compared to assess groundwater dynamics and their relationship with climatic variability and drought conditions.

## Main Methods

The analysis includes:

- Water Table Fluctuation (WTF) method for groundwater recharge estimation
- Streamflow baseflow separation
- Lyne–Hollick filter
- Chapman filter
- Eckhardt filter
- Recession analysis
- Groundwater storage estimation
- Comparison of groundwater storage with drought indices
- Correlation analysis between groundwater-level and streamflow-based methods

## Repository Contents

### `Recharge_Assessment_WTF.ipynb`
Estimation and assessment of groundwater recharge using the Water Table Fluctuation (WTF) method.

### `GW_Storage_Baseflow_Separation.ipynb`
Estimation of groundwater storage using streamflow baseflow separation methods, including Lyne–Hollick, Chapman, and Eckhardt filters.

### `recession_analysis_updated.ipynb`
Groundwater-storage assessment based on streamflow recession analysis.

### `Correlation_WTF_streamflow_method.ipynb`
Correlation and comparison between groundwater-level-based and streamflow-based groundwater assessment methods.

### `Comparison_Drought_Index_GW_Storage.ipynb`
Comparison of groundwater-storage variations with drought indices to investigate the relationship between climatic drought and groundwater availability.

## Study Area

The study focuses on selected groundwater monitoring stations and catchments in **Saxony, Germany**.
